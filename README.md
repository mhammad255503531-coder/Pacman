# Pacman Game in Java 🎮

A console-based Pacman game developed in Java using Object-Oriented Programming concepts. The game includes player movement, random ghost movement, collision detection, score tracking, bonus points, and win/lose conditions.

## 📌 Features

* Pacman movement using keyboard controls
* Random ghost movement
* Collision detection system
* Score and lives tracking
* Bonus point collection
* Custom 20x20 maze
* Win and Game Over conditions
* Interactive console gameplay

## 🛠️ OOP Concepts Used

* Abstraction
* Inheritance
* Polymorphism
* Encapsulation
* Classes and Objects

## 💻 Technologies Used

* Java
* OOP
* Console-based Game Development

## 🎮 Controls

| Key | Action     |
| --- | ---------- |
| W   | Move Up    |
| A   | Move Left  |
| S   | Move Down  |
| D   | Move Right |
| Q   | Quit Game  |

## ▶️ How to Run

1. Clone the repository
2. Open the project in any Java IDE
3. Compile and run the `pacman.java` file

```bash
javac pacman.java
java pacman
```

## 📷 Game Preview

The game runs in the console and displays:

* Pacman (`P`)
* Ghosts (`G`)
* Walls (`#`)
* Food (`.`)
